# Submission Specification

## Required deliverables

According to the official problem statement:
1. Public GitHub repository.
2. Live deployed URL.
3. Illustration video.

The video must:
- be under 100MB
- be strictly 90–180 seconds
- demonstrate signup/login
- adding/completing a task
- leveling up
- page refresh proving persistence
- be publicly accessible without login authorization

## Repository

Must contain:
- frontend source
- backend source
- database/schema
- clean chronological commit history (at least 3 chronological commits)
- detailed README
- `.env.example`

## Pre-submission

Run:
- production frontend build
- production backend check
- database migration check
- E2E smoke test
- Lighthouse
- keyboard-only test
- fresh-browser test
- video playback test

## Final freeze

Once deliverables are validated:
- do not make risky changes
- tag/record the final release commit
- verify live URL one final time
