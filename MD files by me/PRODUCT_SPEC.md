# Product Specification

## Product name

Life RPG

Optional thematic branding can be added, but the gameplay model must remain understandable.

## Product promise

Turn everyday tasks into quests that produce immediate, visible progression.

## Core loop

```text
Create Quest
  ↓
Do Real-World Work
  ↓
Complete Quest
  ↓
XP + Gold + Attribute XP
  ↓
Streak Updates
  ↓
Possible Level Up
  ↓
Rewards / Inventory / Unlocks
  ↓
Next Quest
```

## Core screens

1. Public landing page
2. Login/signup
3. Main dashboard
4. Task/Quest creation
5. Task list / board
6. Character/profile
7. Inventory/shop
8. Activity/history
9. Settings

Keep authenticated navigation simple.

## Product personality

The UI must feel:
- alive
- tactile
- rewarding
- coherent
- playful
- premium
- fast

## Proposed thematic system

Use a **"real-life adventurer"** fantasy/cyber-fantasy hybrid that is broad enough to fit all task categories.

Vocabulary:
- Tasks → Quests
- Points → Gold
- Profile → Character
- Categories → Disciplines
- Streak → Momentum
- Store → Armory
- Badges → Relics

Do not make the theme so heavy that users cannot understand the app.

## Definition of a successful core experience

A first-time user should be able to:
1. sign up
2. create a quest
3. mark it complete
4. see XP/Gold/attribute rewards
5. see progression toward the next level
6. refresh
7. log back in
8. still see the data

## Empty states

Every major authenticated section needs a useful empty state and CTA.
