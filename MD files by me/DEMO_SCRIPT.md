# 90–180 Second Walkthrough Video Script

The official requirement is a screen recording under 100MB and strictly 90–180 seconds demonstrating signup/login, adding/completing a task, leveling up and refreshing to prove persistence. fileciteturn2file0L38-L46

## Target length

~120 seconds.

## 0–10s
Show landing page.

Voice/text:
“Life RPG turns everyday work into quests, XP, levels, streaks and rewards.”

## 10–25s
Sign up/login.

Show:
- authenticated dashboard
- character
- current level
- streak
- Gold

## 25–45s
Create a quest.

Example:
“Complete React Hooks module”
Category: Intellect
Difficulty: Medium

Save.

## 45–65s
Complete quest.

Show:
- satisfying completion animation
- XP gain
- Gold gain
- Intellect increase
- streak update

## 65–80s
Trigger a level-up or show near-level progression.

Show:
- old level
- new level
- new XP bar
- reward/unlock

## 80–100s
Open shop.

Purchase:
- theme
or
- badge/profile frame

Show Gold deduction and inventory ownership.

## 100–112s
Refresh browser.

Show:
- task state
- XP
- level
- Gold
- inventory

all persisted.

## 112–120s
Close with the product dashboard.

Do not spend video time on:
- code
- terminal
- loading screens
- unnecessary settings

Every second should prove a requirement or show polish.
