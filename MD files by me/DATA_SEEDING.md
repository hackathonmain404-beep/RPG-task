# Demo and Seed Data

## Purpose

Seed data makes the product demonstrable without faking primary persistence.

## Allowed seed data

- starter shop items
- starter badges
- starter themes
- optional tutorial/example quest templates

## User data

User-specific progression must be written to the real database.

Do not seed fake progress into a newly registered user in a way that makes the database persistence demo ambiguous.

## Demo account

If a demo account is provided, clearly document it.

Do not use real personal credentials.

## Deterministic demo

Seed:
- shop catalog
- badges
- themes
- optional static achievement descriptions

Avoid seeded fake testimonials, fake user counts or fake social proof.
