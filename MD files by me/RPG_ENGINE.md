# RPG Progression Engine

## Goal

Create a non-linear level system where every next level requires more XP than the previous level.

## Recommended formula

Use cumulative XP thresholds:

```text
XPToReachLevel(L) = BASE_XP * L^1.65
```

with a sensible BASE_XP such as 100.

Do not rely on floating-point equality.

Round thresholds deterministically.

Alternative implementation:
store a threshold table generated by the same formula up to a reasonable maximum level.

## Example

Approximate progression:

```text
Level 1 → 0 XP
Level 2 → 100 XP
Level 3 → 310 XP
Level 4 → 621 XP
Level 5 → 1,000 XP
...
```

The exact values are implementation-defined but MUST be increasing.

## Requirements

The engine must expose pure functions:

```ts
getLevelForXp(totalXp)
getXpRequiredForLevel(level)
getXpIntoCurrentLevel(totalXp)
getXpNeededForNextLevel(totalXp)
getProgressPercent(totalXp)
```

## Level-up behavior

When completing a task:
1. read current XP
2. calculate new XP
3. determine old level
4. determine new level
5. if new level > old level:
   - create level-up event
   - unlock level-based rewards if configured
   - return one or more level-up notifications

## Multi-level jumps

If one reward causes multiple level increases, the engine must support it safely.

Example:
Level 3 → Level 5 from a large reward.

## Anti-cheat

Level and XP are server-owned.

Never allow:
`PATCH /character` with `{xp: ...}`.

## Testing invariants

For levels 1..N:

```text
threshold(level + 1) > threshold(level)
```

Also test:
- 0 XP
- exact threshold
- one XP below threshold
- one XP above threshold
- huge XP
- multiple level jump
